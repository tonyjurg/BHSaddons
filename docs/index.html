BHSaddons

What is BHSaddons?

This repository offers a set of features built specifically for use with the BHSA Text-Fabric dataset. Text-Fabric is a powerful platform for analyzing biblical texts with linguistic and structural detail. To complement this, this feature set focuses on the parashot, the weekly portions into which the Torah is divided. A parasha is a designated section of the Torah, read during weekly synagogue services. Together, the 54 parashot divide the entire five books of the Torah, forming a yearly cycle of reading that is central to Jewish liturgy and tradition.

How to use BHSaddons

Load the additional features alongside BHSA using the Text-Fabric mod option. See the usage guide for installation and examples.

Available features

Seven features describe parashot, aliyot, maftir verses, and surface word boundaries. Browse the feature documentation for descriptions, values, and frequency tables.
